## 5. 期权头寸与真实敞口

> 本节的数字用 `tools/risk_calc.py` 生成，把持仓填进脚本顶部的 POSITIONS 后运行即可。
> **不要只填名义金额。** 名义把深虚值和实值 Put 算成一样，会严重误判——
> 2026-08-01 那期名义 325,900，Delta 调整后的真实敞口只有 75,219，差 4 倍。

**逐笔明细**

| 标的 | 意图（接货型/收租型/卫星投机） | 行权价 | 到期日 | 张数 | 开仓权利金 | 当前标记价 | 浮动盈亏% | 隐含波动率 | Delta | 名义金额 | Delta 敞口 | 若被行权后的计划 |
|------|------|--------|--------|------|------------|------------|-----------|-----------|-------|----------|-----------|------------------|
| | | | | | | | | | | | | |

> 「意图」这一列是本表的核心。接货型 Put = 我真心愿意在盈亏平衡价长期持有，最坏结果是买到好公司；
> 收租型 Put = 我不打算接货，到期前一定平仓，最坏结果是纯现金亏损。两者风险性质相反，
> 适用的行权价关卡完全不同（规则卡 3.3 节 A/B 两套），必须分开统计、分开设额度。
