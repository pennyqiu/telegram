# 期权03 · 价差与组合族

> **本文回答一个具体问题**：规则卡 O6（-25% 情景保证金占用 50.5%，已进追缴区）是当前最要命的两条红牌之一。
> 加一条腿能不能从结构上解决它？答案是能，而且代价是可以算清楚的。

## 一、多加一条腿到底改变了什么

单腿卖 Put 的三个不受控变量，加一条保护腿后有两个变成常数：

| 变量 | 裸卖 / 现金担保单腿 | 加了保护腿（信用价差） |
|------|-------------------|---------------------|
| 最大亏损 | 理论上 = 行权价 × 100 − 权利金 | **= 价差宽度 × 100 − 权利金（固定）** |
| 保证金占用 | 随标的下跌与 IV 扩张而膨胀 | **= 最大亏损（固定，不随行情膨胀）** |
| 崩盘时的 Vega 亏损 | 全额承担 IV 扩张 | 两腿的 Vega 大部分互相抵消 |
| 权利金 | 100% | 通常只剩 50%–70% |
| 能否接货 | 能（这是接货型的全部意义） | **不能** |

**第二行是关键**：信用价差的保证金是**在开仓那一刻就固定下来的**，它不会因为市场跌 25% 而膨胀。
规则卡 O6 那张压力测试表里保证金从 23.4% 一路涨到 146.3% 的现象，在价差结构下**不会发生**。

> **一句话**：单腿卖 Put 在崩盘中会同时遭遇「亏损扩大」和「保证金要求膨胀」两件事，
> 后者才是导致强制平仓的机制。价差把后者变成常数，于是**把「会不会被迫离场」从行情的函数变成了开仓时的选择**。

## 二、Put 信用价差：收租型的正确形态（Q004 裁决依据）

### 构造与算例

以 QQQ 为例（示意，非报价）：现价约 700，卖 45 DTE、0.15Δ 的 640 Put，同时买 620 Put。

| 项 | 单腿裸卖 640P | 640/620 信用价差 |
|----|-------------|----------------|
| 收到权利金（示意） | $600 | $380 |
| 最大亏损 | $63,400（若归零） | **$1,620**（=2,000 − 380） |
| 保证金占用 | 动态，崩盘时可翻数倍 | **$1,620，固定** |
| -25% 情景下的追加占用 | 大幅膨胀 | **0** |
| 权利金 / 最大亏损 | 极高但尾部无界 | 23%（可直接与其它机会比较） |
| 能否接货 | 能 | 不能 |

### 为什么这对收租型是严格改进

收租型的定义（规则卡 3.1）是「赚权利金，不打算持有正股」。既然**从一开始就不要正股**，
那么「能接货」这个属性对它毫无价值——而它为这个用不上的属性支付的代价是**无界的尾部与会膨胀的保证金**。

| 规则卡条款 | 单腿收租型 | 换成信用价差后 |
|-----------|-----------|--------------|
| O6 压力测试（-25% 保证金 ≤ 40%） | ✗ 50.5% | 变成开仓时可算的固定数，可直接设计到达标 |
| O7 偿付能力（现金 ≥ -20% 情景浮亏） | ✗ 缺口巨大 | 最大亏损已知，**偿付桶的需求变成一个确定的数字** |
| O4 指数 Put Delta 敞口 ≤ 15% | △ 刚好触线 | 净 Delta 显著小于单腿（两腿部分抵消） |
| B-第二关 偿付能力 | ✗ 全部不过 | 可以设计成必然通过 |

**这是本区目前给出的最具体、最可执行的一条改进**：它不需要判断力，只需要多挂一条腿。

### 代价与限制（必须同时写下来）

1. **权利金少 30%–50%**。收租型本来的收益预期（净值 +1.5%~2.5%/年）会相应下降到约 +0.8%~1.5%。
2. **两倍的交易摩擦**：两条腿的点差与佣金。**深虚值远月的保护腿点差往往很宽**，实际成本高于理论。
3. **提前指派风险仍在**（美式期权）：短腿被提前指派时，长腿不会自动对冲，需手动处理。
4. **不能接货**——所以它**只能替代收租型，绝不能替代接货型**。回撤响应阶梯里的每一笔都必须保持单腿现金担保。

## 三、中性波动率结构（宽跨、铁鹰、铁蝶、日历）：为什么整族禁用

| 策略 | 构造 | 卖的是什么 | 长期实证 |
|------|------|-----------|---------|
| 宽跨式 | 卖虚值 Put + 卖虚值 Call | 双向的 Theta + Vega | 学界与业界都验证有正期望，但双向尾部 |
| 铁鹰（CNDR） | 宽跨式两侧各买一腿 | 区间 + Vega，尾部封顶 | CBOE CNDR 指数波动率 7.23%，为全部期权指数最低 |
| 铁蝶（BFLY） | 卖平值跨式 + 两翼买入 | 押「钉住」 | BFLY 在 1986–2015 的 354 个月中仅 2 个月亏损超 6%（标普 15 个月） |
| 日历 / 对角 | 卖近月 + 买远月 | 期限结构与 IV 变化 | 依赖 IV 曲面形态，无公开长期基准 |

数据看着不难看（尾部比标普还小），**但禁用理由与收益率无关**：

1. **没有锚。** 本体系所有期权的行权价必须来自标的档案的合理买入区间（规则卡 F1、B 组第一关的设计意图）。
   中性结构的行权价只能来自「概率 / Delta / 区间猜测」——这正是 2026-08-01 复盘定性为「凭盘面感觉挂单」的做法。
2. **要求一种本组合并不具备的能力**：对波动率与区间有独立观点。组合的信息优势在「哪家公司值多少钱」，不在「未来 45 天会不会横盘」。
3. **占用注意力**。中性结构需要频繁双向调整；而本体系已经证明自己的瓶颈是**执行率**（六条自写规则全部未执行），不是策略数量。

> **一个诚实的补充**：如果目标变成「用一小笔钱做与股票组合低相关的收益」，铁鹰是一个可讨论的候选，
> 因为它的相关性与尾部都比单腿卖 Put 好。但那需要先在规则卡里给出「非相关性策略」的独立额度桶
> （类似 P5 卫星投机仓 ≤ 5%），并接受它是投机而非投资。**在此之前维持禁用。**

## 四、PMCC（穷人备兑）与 LEAPS 替代持股（Q009 观察）

### 构造

- **LEAPS 替代持股**：买入 12–24 个月、深实值（Delta 0.75–0.85）的 Call，用它代替 100 股正股。
- **PMCC**：在上面那条长腿之上，卖近月虚值 Call 收租。

### 数学本质

LEAPS 深实值 Call ≈ 正股 + 内含融资（隐含利率≈无风险利率+借券成本）− 股息 + 一份时间价值保险。
所以 PMCC = **杠杆化的备兑 Call**。它在纸面上很有吸引力：资金占用只有正股的 20%–30%，租金率看起来高得多。

### 为什么对本组合是「观察」而不是「白名单」

| 冲突点 | 说明 |
|-------|------|
| **到期日 vs 15–20 年持有期** | 每 12–24 个月强制展期一次，每次都是摩擦 + 再决策点。长期持有的核心优势正是「不需要不断做决定」 |
| **Vega 不对称** | 长腿 Vega 远大于短腿。IV 收缩时（牛市中常见）长腿贬值可以吃掉全部租金——**赚了租金亏了本金** |
| **无股息** | 持有 Call 不收股息；对 MSFT / QCOM 这类分红股是实打实的损耗 |
| **短腿被行权的处理** | 短腿若被行权，你没有正股交割，需要行权长腿或买回，容易在压力下操作失误 |
| **与「接货型」精神冲突** | 本体系用期权是为了**得到股票**；PMCC 的目的是**不持有股票却拿到敞口**，方向相反 |

**唯一可讨论的场景**：已经决定建仓某标的、买区已到、但**现金要几周后才到账**。
此时用一张深实值 LEAPS 占位、到账后换成正股，是一种过渡工具。若使用，必须：
① 写进决策日志（含预计换成正股的日期）；② 不在其上卖任何 Call；③ 计入 O2 总多头敞口。

## 五、修复类与比率结构：明确禁用

| 策略 | 声称的用途 | 真实作用 |
|------|-----------|---------|
| 比率价差（1 买 2 卖） | 「低成本修复浮亏」 | 多卖出的那一腿是**新增裸露风险**，用扩大敞口换账面好看 |
| 卖 Call 摊薄浮亏正股 | 「降低成本」 | 锁死反弹（见 [02 §4](./02-收租族-卖Put与备兑Call.md)） |
| 加倍卖出（martingale） | 「摊平」 | 在亏损方向加杠杆，是账户毁灭的标准路径 |

**统一裁决：禁用。** 判据只有一句：**任何「用来处理已有亏损」的期权结构，都是在扩大敞口换取心理安慰。**
已有亏损的正确处理方式在规则卡 T1–T5 里已经写好——平仓、展期（≤1 次）、或按 playbook 执行，没有第四种。

## 六、本文给出的规则建议汇总

| 建议 | 对应规则卡位置 | 状态 |
|------|--------------|------|
| 收租型卖 Put 一律改为 Put 信用价差（宽度 ≤ 净值 0.5%/笔） | 3.1 收租型定义、3.3-B | 待季度复盘 |
| 接货型保持单腿现金担保，不得使用价差 | 3.3-A | 待季度复盘 |
| 中性波动率结构（宽跨/铁鹰/铁蝶/日历）永久禁用 | 新增条款 | 待季度复盘 |
| 比率 / 修复 / 加倍类结构永久禁用 | 新增条款 | 待季度复盘 |
| LEAPS 仅作建仓过渡工具，且不得叠加卖 Call | 新增条款 | 待季度复盘 |
