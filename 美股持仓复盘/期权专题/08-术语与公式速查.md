# 期权08 · 术语与公式速查

> 只收录**本体系实际会用到**的定义与算式，按「填快照、检查规则卡」的顺序排列。
> 与规则卡口径不一致的地方，一律以规则卡为准。

## 一、希腊字母（只需记住它在本体系里管什么）

| 字母 | 定义 | 在本体系里管什么 |
|------|------|----------------|
| **Delta（Δ）** | 标的涨 $1 时期权价格的变化 | ① **额度口径**（O2/O3/O4/O5 全部是 Delta 敞口）② 近似实值概率 → 收租型第一关 ≤0.20 |
| **Gamma（Γ）** | 标的变动时 Delta 的变化速度 | 为什么禁 ≤7 DTE（Gamma 爆炸区，A1） |
| **Theta（Θ）** | 每天流逝带来的期权价值衰减 | 卖方收入的表现形式；21–45 DTE 是衰减最陡的一段 |
| **Vega（ν）** | IV 变动 1 个百分点时期权价格的变化 | **目前规则卡完全没有约束的维度**（Q003，建议新增 O8） |
| Rho（ρ） | 利率敏感度 | 可忽略（除 LEAPS） |

## 二、核心算式

### 2.1 名义金额（Notional）

```
名义金额 = 行权价 × 100 × 张数
```

**用途**：只用于「接货需要多少现金」（O1、接货型第四关）。
**不要用它衡量风险**——规则卡 3.2 已经明确：名义把深虚值和实值算成一样，
当前 325,900 的名义，Delta 调整后真实敞口只有 75,219（76.2% vs 17.6%，差 4 倍多）。

### 2.2 Delta 敞口（本体系的风险口径）

```
Delta 敞口 = |Delta| × 标的现价 × 100 × 张数
```

**这是 O2/O3/O4/O5 的统一口径。** 含义是「这笔期权相当于持有多少美元的正股」。

### 2.3 总多头敞口（O2）

```
总多头敞口 = 股票市值 + 期权 Delta 敞口合计
O2 要求：总多头敞口 ≤ 合并净值 × 115%
```

超过 100% 就是有杠杆。2026-08-01 的值是 119%。

### 2.4 卖 Put 的盈亏平衡点

```
盈亏平衡点 = 行权价 − 收到的权利金（每股）
实际接货成本 = 盈亏平衡点
```

接货型第二关就是查这个数是否 ≤ 标的档案的「合理买入区间上限」。

### 2.5 权利金年化（用于比较机会）

```
单周期收益率 = 权利金 ÷ 抵押金额（= 行权价 × 100）
年化 ≈ 单周期收益率 × (365 ÷ 持有天数)
```

**两个必须注意的地方**：
① 分母要用**抵押金额**（现金担保口径），用保证金做分母会得到虚高的数字——那是杠杆，不是收益率；
② 按 45 DTE 开仓但 21 DTE 平仓，实际持有天数是 24 天，不是 45 天。

### 2.6 信用价差的最大亏损与保证金

```
最大亏损 = (卖出腿行权价 − 买入腿行权价) × 100 − 收到的净权利金
保证金占用 ≈ 最大亏损（开仓即固定，不随行情膨胀）
风险回报比 = 净权利金 ÷ 最大亏损
```

### 2.7 IVR（IV Rank）

```
IVR = (当前 IV − 过去一年最低 IV) ÷ (过去一年最高 IV − 过去一年最低 IV)
```

**只能与该标的自己比，不能跨标的比。** 补充看 IV Percentile（过去一年有多少比例的天数 IV 低于今天），
它不会被单日尖峰扭曲。

### 2.8 打平胜率（评估止盈止损配对）

```
打平胜率 = 平均亏损 ÷ (平均盈利 + 平均亏损)
```

规则卡 T1（止盈 50% → 0.5C）+ T2（浮亏 100% → 1.0C）→ 打平胜率 66.7%。推导与三个漏洞见 [02 §3](./02-收租族-卖Put与备兑Call.md)。

## 三、三个容易搞错的近似

| 近似说法 | 实际情况 |
|---------|---------|
| 「Delta = 到期实值概率」 | 只是**近似**。实际实值概率通常**略高于** \|Delta\|（因为波动率偏斜与分布非对称）。0.20Δ 的胜率按 78%–80% 估，不要按 80% 精算 |
| 「胜率 80% 所以能赚」 | 胜率与期望值是两件事。0.5C 盈 / 1.0C 亏的配对需要 66.7% 才打平——**胜率必须与盈亏比一起看** |
| 「权利金翻倍 = 亏 200%」 | 权利金翻倍时，买回成本 2C、已收 C，**净亏 1C（即 -100%）**。规则卡 T2 说的就是这个 |

## 四、期权代码与到期日

美式期权代码（OCC 格式）：`QQQ 260918P00620000`

| 段 | 含义 |
|----|------|
| `QQQ` | 标的 |
| `260918` | 到期日 2026-09-18 |
| `P` | Put（`C` = Call） |
| `00620000` | 行权价 620.000（后三位是小数） |

**DTE = 到期日 − 今天**（自然日）。规则卡 A1 用 30–45 DTE 入场、A3 在 21 DTE 无条件处理，
所以一张 45 DTE 的仓位正常持有期约 24 天。

**美式提前指派的两个常见触发**：① 深度实值且时间价值接近 0；② **除息日前的实值 Call**（对方为拿股息提前行权）。
持有备兑 Call 时要留意除息日。

## 五、一次开仓需要填的最小信息集

照抄这张表进决策日志，就能满足规则卡的自检要求：

| 字段 | 例 |
|------|-----|
| 标的 / 到期 / 行权价 / 张数 | QQQ / 2026-09-18 / 620 / 2 |
| **意图（接货型 or 收租型）** | 收租型 |
| 权利金（每张 / 合计） | $6.00 / $1,200 |
| Delta（开仓时） | -0.15 |
| **Delta 敞口** | 0.15 × 700 × 100 × 2 = $21,000 |
| 名义金额 | 620 × 100 × 2 = $124,000 |
| 盈亏平衡点 | 614.00 |
| 抵押/保证金来源 | 现金担保 / 保证金（**收租型须写明偿付桶余额**） |
| 开仓时 VIX / IVR / 期限结构 | 15.8 / 43% / 升水 |
| 行权价依据 | 标的档案买区上限（或：不适用，收租型按 Delta） |
| 止盈 / 止损 / 时间闸门 | 50% GTC / 浮亏 100% / 21 DTE |
| 加上这笔后 O2–O7 是否达标 | 逐项填 |
