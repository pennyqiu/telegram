# 期权专题讨论区

> 建区日期：2026-08-15。
>
> **这个区解决什么问题**：体系里已经有「能不能开」（[投资规则卡](../投资规则卡.md)）和「具体怎么挂」（[playbooks/](../playbooks/)），
> 但一直缺一层：**为什么用这个策略，而不是另外那十几种。**
>
> 实际情况是：账户里长期只用两招——卖 Put、备兑 Call；而两次真实事故（QCOM 155P 浮亏 -101%、DRAM 55P -80%）
> 的根因之一，是**把「做空波动率」当成了「买入纪律」**。这类混淆不是纪律问题，是**策略认知问题**——
> 没有在事前把每种策略的盈亏结构、希腊字母、失效场景摊开看过一遍，就没法知道自己手里那张是什么。
>
> 所以这个区做三件事：① 把主流策略调研清楚；② 用可查的实证证据判定它们的长期表现；
> ③ 逐条裁决**哪些进入本组合白名单、哪些永久禁用**，并把裁决映射回规则卡条款。

## 与既有文档的分工

| 文档 | 回答的问题 | 变更频率 |
|------|-----------|---------|
| `标的档案/<代码>.md` | 我为什么持有它、买区在哪 | 事件驱动 |
| **本区** | **在这个标的上，该用哪种期权结构？为什么不用另一种？** | **季度或有新证据时** |
| `投资规则卡.md` | 这笔能不能开、多大、什么价位 | 仅季度/年度 |
| `playbooks/<代码>-*.md` | 挂什么行权价、什么周期、怎么展期 | 事件驱动 |
| `决策日志.md` | 规则到底执行了没有 | 每次操作 |

**本区不产生交易指令。** 它的输出只有两种：进入白名单的策略清单，以及需要写进规则卡的条款建议。
**任何裁决要变成可执行规则，必须走规则卡的 F5 修订纪律（只能在季度或年度复盘时落地）。**

## 用大模型跑期权议题（推荐流程）

不要把 01–08 九篇都喂给模型——那既超上下文又会稀释重点。用两个文件就够：

| 场景 | 贴什么 | 说明 |
|------|-------|------|
| **随手问一个期权问题** | [09 知识底稿](./09-知识底稿-给大模型.md) 的正文 + 你的问题 | 底稿自包含：画像、账户硬约束（P/C/O/T/A 全部阈值）、白名单、实证事实、**十个本账户特有的陷阱** |
| **跑一条完整的新议题并入库** | 09 知识底稿正文 + [`../期权议题调研提示词.md`](../期权议题调研提示词.md) 正文 | 提示词的输出格式与本区结构一一对应：第 1 部分直接粘进下方议题看板，第 2 部分粘进 07，第 3 部分粘进 06 |

**两条使用纪律**：

1. **09 是投影，不是产地。** 数字要改先改源文件（规则卡 / [06 实证证据档案](./06-实证证据档案.md)），再回来同步 09 并登记。
2. **模型的输出一律是「建议 + 待季度复盘」**，不得直接改规则卡（F5）。
   若模型给出的结论恰好让现有不合规头寸变得合规，**按提示词要求它必须自己先警告这个时机可疑**。

## 一句话现状结论（2026-08-15 首轮调研后）

**卖方策略长期有效这件事，证据是扎实的；但账户里执行的那个版本，恰好落在证据不支持的那一侧。**

三条最关键的事实（完整数据与来源见 [06 实证证据档案](./06-实证证据档案.md)）：

1. **CBOE PUT 指数（现金担保卖 ATM Put）1986-06 至 2018-12 年化 9.54%，波动率 9.9%，夏普 0.64 —— 高于标普 500 的 9.80% / 14.9% / 0.45。**
   但请注意它的前提：**100% 现金担保 + 卖指数 + 机械月度滚动**。这三条同时成立才有那条曲线。
   账户此前的做法是保证金裸卖，**不在这个证据覆盖的范围内**。
2. **卖方的低波动是用「负偏 + 厚尾」买来的**：PUT 指数偏度 -2.10、峰度 9.72，均为全部对比资产中最差。
   这与规则卡 O6/O7 的压力测试思路完全一致——**卖方策略的真实约束从来不是收益率，是能不能活过左尾**。
3. **在 AI 龙头上系统性卖备兑 Call，是把这个组合最值钱的东西卖掉。**
   QYLD（纳指 100 备兑 ATM Call）2013-12 至 2026-08 年化 8.65%，同期 QQQ 19.14%。
   这直接冲撞规则卡 1.3 采用的「QQQ 式让赢家跑」——见议题 **Q001**。

## 讨论规范（写给未来的自己和 AI）

1. **议题只追加，不改写。** 结论变了就在原议题下加一条日期新记录，并把「一句话结论」更新到看板；不要删掉旧结论——被推翻的判断本身是最有价值的记录。
2. **任何数字必须带来源与样本期。** 数字一律进 [06 实证证据档案](./06-实证证据档案.md)，别的文件引用它。样本期不同结论会翻转（例：BXM 在 1986–2011 样本里夏普高于标普，加进 2019–2025 大牛市后已基本持平），**不写样本期的数字等于没有数字**。
3. **裁决必须落到三个动作之一**：进白名单（并写明限额）、进观察（并写明观察指标）、永久禁用（并写明禁用理由）。不允许「以后再看」。
4. **不允许为了让某笔已经想做的交易合规而改裁决**——与规则卡开头同一条纪律。
5. **本区可以讨论任何策略，但不得在此处下单**。要执行必须先落进规则卡或 playbook。
