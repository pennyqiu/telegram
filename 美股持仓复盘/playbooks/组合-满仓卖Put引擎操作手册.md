> ⚠️ 本手册仅供信息参考，不构成投资建议。满仓 + 融资卖 Put 具高杠杆、非线性、潜在大额亏损与强制平仓特征。

## 四、引擎第一性原理（无现金 = 融资卖 Put）

| 要点 | 内容 |
|------|------|
| 保证金来源 | 非现金，而是 SPY/QQQ 的**融资额度（loan value）**，PM 下满仓仍有大额账面剩余流动性 |
| 与有现金版的根本差异 | **被行权 = 被动融资接货 = 账户瞬间变 1.2–1.5× 杠杆** |
| 因此铁律 | 不是"愿意接货"，而是**"永远在被行权前平仓或展期，绝不接货"** |
| 名义敞口预算的作用 | 防止"万一全被行权"时杠杆失控 |

## 五、名义敞口预算（决定能卖几张）

1 张 QQQ Put ≈ 100 股 × ~$712.60 → 取 0.20Δ（约 7% 虚值行权价 ~$663）的名义约 **$66,300**，相当于净值的 16.6%。以"假设全部被行权后杠杆 ≤ 1.5×"倒推张数上限：

| 同时在场张数 | 总名义敞口 | 占净值 | 全被行权后杠杆 | 结论 |
|------|------|------|------|------|
| 1 张 | $66,300 | 16.6% | 1.17× | 安全 |
| 2 张 | $132,600 | 33% | 1.33× | **常态上限** |
| 3 张 | $198,900 | 50% | 1.50× | 仅恐慌期、分批、绝对上限 |
| 4 张+ | $265,200+ | 66%+ | 1.66×+ | **禁止（杠杆失控）** |

> SPY Put 名义略高（SPY $744.78 → ~$69,300/张），可与 QQQ 混用但**合并计入同一敞口预算**。名义按实时价重算——股价上涨后单张名义变大，要相应减少张数。

## 六、VIX 择时分档（比有现金版更保守）

| VIX 区间 | 最大在场张数 | Delta 锚定 | 说明 |
|------|------|------|------|
| < 18（当前 15.81） | 0（停摆） | — | 溢价不足以补偿无缓冲的杠杆风险，宁可不做 |
| 18 – 22 | 1 | -0.15 | 小额试水，深虚值留纵深 |
| 22 – 28 | 2 | -0.15 ~ -0.20 | 常态满载，权利金开始变肥 |
| > 28 | 3（上限） | -0.15 | 恐慌肥溢价，但也是崩盘区，**分批进、别一次打满** |

**双重确认**：VIX 决定"整体敢开几张"（宏观闸门）；QQQ/SPY 自身 **IVR > 30** 决定"这个标的现在值不值得卖"（标的择时）。两者同时满足才开仓。当前 QQQ IVR ~43% 达标，但 VIX 15.81 未过 18 → **暂不开仓**；SPY IVR ~18% < 30 → SPY 暂停，达标后也只做 QQQ。

## 七、开仓与管理规则

### 7.1 开仓清单

| 项 | 参数 |
|------|------|
| 标的 | 仅 QQQ / SPY（**拒绝单股**，避免财报跳空与逼空） |
| 到期 | 45 DTE 左右 |
| 行权价 | -0.15Δ（约 7–8% 虚值） |
| 方向 | Sell Put |
| 数量 | 按 VIX 分档 + 名义预算，1 张起 |
| 限价 | 挂中间价，不市价吃单 |

### 7.2 生命周期管理

| 触发 | 动作 |
|------|------|
| 成交即刻 | 挂 **50% 权利金 GTC 买平单** |
| 浮亏达 2× 权利金 | 检查点：评估提前展期（非机械等 21 DTE） |
| 21 DTE 未止盈 | 强制平仓或 Roll Down & Out（收净 credit） |
| 跌破行权价 | 立即展期，**绝不接货** |
| 接近行权日仍价内 | 务必在行权前平掉，杜绝被指派 |

## 八、硬红线与崩盘协议（无现金版的生命线）

### 8.1 剩余流动性红线：40%

每日收盘查看 IBKR「剩余流动性 / 净清算值」：

- 一旦跌破 **40%**：①立即停止新开仓；②买平最近到期的那张 Put 释放保证金；③若仍 < 40%，减一张核心 ETF 现货。
- 这条**优先于任何收益目标**——它是无缓冲账户唯一的护栏。

### 8.2 崩盘四步协议（VIX > 35 或指数单周 > -8%）

| 步骤 | 动作 |
|------|------|
| 1 | 冻结引擎：不再开任何新 Put |
| 2 | 把在场 Put 全部 Roll Down & Out（更低行权价 + 更远到期，收净 credit） |
| 3 | 复核剩余流动性；若逼近 40%，主动减仓降杠杆，**不等券商 margin call** |
| 4 | 等 VIX 回落、流动性恢复到 55% 以上，再重启引擎 |

> **为什么不接货（哪怕愿意长持 QQQ）**：无现金版接货 = 融资买入 = 在下跌中主动加杠杆，正是强平的导火索。这里的纪律是纯粹的展期，不接货——用空间换时间，让 Theta 重新工作。

## 十二、风险揭示

1. **满仓无缓冲 + 融资卖 Put = 杠杆**：牛市放大收益，熊市四杀（SPY/QQQ/科技/Put 同亏）+ 保证金膨胀，可能触发强制平仓。红线与展期纪律是唯一护栏。
2. **收益含强烈后视镜偏差**：NVDA +68%/年、TSM +36%/年不可复制，前瞻请用 10%–14%。
3. **半导体集中度 ~16%**：AI 算力叙事一旦证伪（云厂 capex 削减、竞品、出口管制），NVDA+TSM 会共振重挫。
4. **TSM 台海地缘尾部**：唯一非美标的，可能出现指数成分股不会有的跳空式风险。
5. **深熊回撤 -50~58%**：泡沫式情景下 $400k 可回撤至 ~$16.8 万，需能扛住不砍仓、不停引擎。
