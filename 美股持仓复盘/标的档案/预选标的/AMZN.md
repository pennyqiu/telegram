## 二、投资逻辑（研究版结论）

**一句话**：好公司、错用途——用 AMZN「分散」科技仓，是把油加进已经在烧的炉子。

**展开**：

1. **需求端身份决定一切**：你的 NVDA / TSM / DRAM / 半导体 ETF 敞口，本质是在赌「云厂 capex 继续」。而 AMZN 正是那几个下单的买家之一（与 MSFT / GOOGL / META 并列）。**买 AMZN 不是买了个不相关的资产，是把同一个变量押了两次。** Beta 1.45 也印证了这一点。
2. **基本面确实很好**：AWS 单季 +37%，是 18 个季度以来最快；营业利润 +43%；AWS 经营利润率冲到 **39.4%**。这些数字没有水分，而且比对手（Azure +43%、Google Cloud +82%）也不算落后太多。
3. **但估值不便宜**：市场标价的 22x PE 是被一次性收益污染的假象，**真实倍数约 30x**（见第四节）。
4. **结论属性**：如果你是空仓、只想单独赌 AWS，那是另一场讨论。在**你当前的持仓结构**下，显性化加仓与「降低 AI 赌注集中度」这个目标直接冲突。

## 四、估值真相：为什么 22x 是幻觉

### 4.1 一次性收益的剔除计算

| 步骤 | 数值 | 说明 |
|------|------|------|
| TTM 净利润（财报） | **$1,352.8 亿** | |
| 减：Anthropic 重估税前收益 | -$534.0 亿 | 公司披露 |
| 加回：对应的离散税项 | +$159.0 亿 | 上半年披露，主要归因于此 |
| **= 税后一次性影响（估算）** | **约 -$375 亿** | |
| **调整后 TTM 净利润（估算）** | **约 $978 亿** | |
| 摊薄股数 | 约 108.7 亿股 | 由 $1,352.8 亿 ÷ $12.44 反算 |
| **调整后 TTM EPS（估算）** | **约 $9.00** | |
| **调整后 TTM PE** | **约 30.5x** | $274.48 ÷ $9.00 |

**验证**：调整后 TTM PE **30.5x** 与市场给的 **Forward PE 29.54x** 几乎完全一致。✅ 两个独立数字互相印证，说明这个剔除是对的——**市场其实一直在按 30x 定价，只是财报口径的 22x 把它掩盖了。**

> ⚠️ 上表标注「估算」的行是我的推算：公司只披露了上半年 $159 亿离散税项「主要归因于」Anthropic 重估，未拆分到单季，也未披露 Q1 是否含类似收益。因此调整后 EPS 有误差，但方向和量级是可靠的。

### 4.2 为什么 PE 历史分位法对 AMZN 完全失效

| 统计量（近 5 年 TTM PE） | 数值 |
|------------------------|------|
| 最低 | 19.2x |
| 中位数 | 51.3x |
| 平均 | **63.4x** |
| 最高 | **245.9x** |

**这组数字没有任何参考价值**。原因是 2022–2023 年 AMZN 的净利润几乎归零（2023 Q1 的 TTM EPS 只有 **$0.42**），分母趋近于 0 会让 PE 趋近于无穷大。所以「AMZN 当前 38.3x 处 30 百分位、低于历史均值 63.4x」这类结论是**统计噪音，不是估值判断**。

**对 AMZN 该用什么**：
- **EV/EBITDA = 18.29x**（在 D&A 线以上，不受 Anthropic 这类营业外项目污染）
- **调整后 PE ≈ 30.5x**（第 4.1 节）
- **分部估值**（第 4.3 节）
- ❌ **不能用 P/FCF**（FCF 为负）
- ❌ **不能用 PE 历史分位**（分母失真）

### 4.3 分部拆解：市场在为 AWS 付多少钱？（粗算，假设已标明）

> 方法：从企业价值 $3.09 万亿里，先按不同倍数给零售业务估值，剩下的就是市场对 AWS 的隐含标价。  
> 零售（北美+国际）经营利润按上半年年化约 **$411 亿**；AWS 经营利润按上半年 $307.8 亿年化约 **$616 亿**。

| 假设零售值多少 | 零售估值 | AWS 隐含估值 | **AWS 隐含倍数** |
|---------------|----------|-------------|----------------|
| 15x 经营利润 | $6,170 亿 | $2.47 万亿 | **约 40x** |
| 20x 经营利润 | $8,220 亿 | $2.27 万亿 | **约 37x** |
| 25x 经营利润 | $1.03 万亿 | $2.06 万亿 | **约 33x** |

**读法**：市场在按 **33–40 倍经营利润**给 AWS 定价。对一个增速 37%、利润率 39.4% 且在加速的资产，这个价格**不算离谱，但也谈不上便宜**。它隐含的假设是：AI 云需求的高速增长至少还要持续好几年，而且那 $2,200 亿 capex 能转化成对应的回报。

**这恰恰是你组合里已经重仓押注的那个假设。**

## 七、看空视角（一个理性空头会怎么打）

1. **Capex 回报不及预期**：$2,200 亿砸下去，如果 AI 收入不能跟上，折旧会在两三年内吞掉利润率。**这个风险与你的 NVDA/TSM/DRAM 仓位是同一个风险。**
2. **FCF 长期为负**：利率或风险偏好一变，「用未来现金流估值」的资产杀得最狠。
3. **估值实际是 30x 不是 22x**：一旦市场普遍剔除 Anthropic 收益，「便宜」的叙事就没了。
4. **Anthropic 重估可以反向发生**：这次向上重估贡献了 $534 亿，下一轮融资若估值下调，同样的会计准则会要求**向下**重估。**这是一把双刃剑，市场现在只看到了刀刃的一面。**
5. **零售业务利润率只有 7.9%/4.1%**：它占了 79% 的营收，却是个薄利生意，且直面关税、劳动力成本、消费降级。
6. **云竞争**：本季 Google Cloud +82%、Azure +43%，AWS 的 +37% 虽在加速，但仍是三家里最慢的。
7. **Q3 指引低于共识**。
8. **对你最关键的一条**：以上七条不管对不对，**都改变不了「高相关」这个事实**。这是组合构建问题，不是公司质地问题——而组合构建问题不能靠「这家公司很好」来解决。
