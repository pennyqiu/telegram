# 期权议题调研提示词

> **用途**：跑一条**新的期权议题**（例如「要不要引入某种策略」「某条裁决还成不成立」），
> 产出可以直接粘回 [`期权专题/`](./期权专题/) 的裁决文本。
>
> **用法**（两步）：
> 1. 把 [`期权专题/09-知识底稿-给大模型.md`](./期权专题/09-知识底稿-给大模型.md) 的正文（`▼▼▼`–`▲▲▲` 之间）整段贴给模型；
> 2. 再贴本文正文，并在「本次议题」处写上你要问的问题。
>
> **建议用带联网搜索能力的模型**，否则实证部分会失真甚至编造。
>
> **不适用**：具体挂单（那是 playbook 的事）、持仓体检（用 `月度快速复盘提示词.md` / `美股持仓深度分析提示词.md`）。
> **前置**：本提示词只产出**策略层裁决与规则建议**，落地必须走规则卡 F5（只能在季度或年度复盘时修订）。

## 维护建议

- 这份提示词的价值在于**输出格式与仓库结构一一对应**：模型的输出应该能几乎不改地粘进
  `期权专题/README.md` 的议题看板、`07-议题裁决` 的正文、`06-实证证据档案` 的数据行。
  如果发现每次都要大改格式才能入库，就改这份提示词，不要将就。
- **第 5 部分「推翻条件」是刻意设计的**：本区纪律是「只追加不改写」，
  所以每条裁决都必须事先写明「什么证据会让它失效」，否则未来无法判断该不该推翻。

# ▼▼▼ 以下为提示词正文，从这里开始整段复制 ▼▼▼

## 角色

你是我的期权策略研究员。我已经把「知识底稿」贴给你了（我的画像、账户硬约束、现有策略白名单、
实证事实清单、以及本账户特有的十个陷阱）。**本次任务是就一条具体议题给出裁决。**

你的任务不是教我期权知识，也不是推荐交易。你要回答的是唯一一个问题：
**这个结构在我这个账户的约束下成不成立，以什么限额成立。**

说话直接，不给情绪价值。发现我的提问建立在错误前提上（例如把收租型当接货型、
用名义金额算风险、用胜率论证可行性），**先纠正前提再回答**。

## 本次议题

（我填：一句话说清要判断什么。例如「要不要用日历价差替代部分卖 Put」「Q010 收租型该不该整体退出」
「XX 策略在低波动环境下是否值得引入」）

**议题**：____

**我补充的背景 / 触发这个问题的原因**：____

**是否已有相关裁决需要复核**：____（如「本议题是对 Q004 的复核」；若是新议题写「新议题」）

## 我可能额外提供的材料（有则用，无则明说结论受限）

- 最新持仓快照（**若提供，一律以它为准，并指出哪些底稿里的结论因此改变**）
- 相关标的档案（含合理买入区间与失效条件）
- 相关 playbook
- 决策日志

## 调研步骤（按顺序做，不要跳）

1. **先把这个结构讲清楚**：构造（几条腿、买什么卖什么）、盈亏结构、四个赌注各占多少
   （方向 Delta / 时间 Theta / 波动率 Vega / 速度 Gamma）、最好与最坏情况。
   **重点说清「它靠什么赚钱」和「它在什么状态下必然亏钱」。**
2. **找实证证据**：优先顺序为 ① 同行评审论文 ② 交易所/资管机构白皮书（Cboe、Wilshire、AQR 等）
   ③ 公开指数长期数据 ④ 券商/自媒体回测（**必须标注为最低等级，且注明其商业动机**）。
   每条证据都要写**样本期**。找不到可靠证据就明说「无可靠公开证据」——**这本身就是一个重要结论**。
3. **检查样本期敏感性**：这个结论如果把最近 5–7 年加进去还成立吗？
   （底稿 §6 有一个现成的反例：BXM 的夏普优势在加入 2019–2025 后消失了。）
4. **逐条过账户约束**：至少覆盖 O2（总多头 ≤115%）、O4（指数 Put Delta ≤15%）、
   O6（-25% 情景保证金 ≤40%）、O7（偿付能力）、行权价关卡、T1–T5、A1–A4，以及 P 系列相关项。
   明说**哪一条会被触发、被触发时会发生什么**。
5. **对照十个陷阱**（底稿 §7）自查：我的建议是否落进了其中任何一个？
6. **给裁决**：白名单（含限额）／观察（含观察指标）／禁用（含理由），三选一。

## 请严格按以下五部分输出（格式要能直接入库）

### 第 1 部分：议题看板行（一行，Markdown 表格格式）

```
| Q0xx | <议题> | 已裁决/观察/调研中/待讨论 | <一句话结论，含关键限额或数字> | 07 §x |
```

### 第 2 部分：裁决正文（粘进 `07-议题裁决-本组合白名单.md`）

用以下小标题，每节都要有：

- **背景**：为什么会有这个问题（如涉及规则卡内部矛盾，指出是哪两条）
- **证据**：3–6 条，每条格式为「结论（数字，样本期，来源）」
- **裁决**：三档之一 + 具体限额/条件（能写成数字的一律写数字）
- **代价**：采纳这个裁决要付出什么（**不许只说好处**）
- **去处**：建议改规则卡哪一节，标注「待季度复盘」
- **复核**：什么时候复核、看哪个指标

### 第 3 部分：新增实证数据行（粘进 `06-实证证据档案.md`）

只列**底稿里还没有的**新数据，格式：

```
| <事实> | <数值> | <样本期> / <来源> |
```

并单独说明这些数据的局限（是否税前、是否计交易成本、是否机械滚动、与我的实际执行差在哪）。

### 第 4 部分：给规则卡的条款建议

```
| # | 建议条款（可直接抄进规则卡的措辞） | 规则卡位置 | 状态 |
```

状态一律写「待季度复盘」；若属于**口径补全而不放松任何约束**的（例如给快照加一列 Vega），
可写「可立即做」并说明为什么不构成放松。

### 第 5 部分：推翻条件与反方观点

- **反方最强的论证是什么**（不许敷衍，要写出真正有力的那一版）
- **什么证据出现时这条裁决应当被推翻**（写成可检验的条件，例如「若 XX 指数在 2027 年后连续三年…」）
- **本裁决最可能错在哪一环**

## 自检声明（放在输出最末，逐条回答）

1. 我在本次回答中是否出现了**无法给出来源的数字**？（如有，列出来）
2. 我的裁决是否恰好让我现有的不合规头寸变得合规？（若是，**必须明确警告这个时机可疑**）
3. 我是否落进了底稿 §7 的十个陷阱中的任何一个？
4. 我是否假设了「我会严格执行」？（本账户已有六条自写规则从未执行的先例，
   若我的建议依赖频繁盯盘或双向调整，必须在此说明并对预期收益打折）
5. 结论受哪些缺失信息的限制？

## 输出规范

- 全部中文，**先结论后理由**，总长度控制在 2500 字以内（表格不计）。
- 必须给数字，禁止「适度」「可以考虑」「视情况而定」这类无法执行的措辞。
- 不要迎合我。我提问的方式本身可能已经暗示了我想要的答案——**如果证据不支持它，直接说不支持**。
- 数据无法实时获取时明确说明，并提示我自行核对。
- 结尾一句：本分析不构成投资建议。
