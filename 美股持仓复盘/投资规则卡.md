# 投资规则卡

> **这份文件的作用**：把「不追高」「不加杠杆」这类口头纪律，翻译成不需要判断、只需要填数字和比大小的硬规则。
>
> **为什么需要它**：2026-08-01 首次深度复盘发现，[playbooks/](./playbooks/) 里两份自己写的操作手册中，
> 多条机械规则（QCOM 跌破 175 防御性展期、DRAM 权利金缩水止盈与破位止损）早已触发但从未执行。
> 缺的不是纪律条文，是**定期把条文和当前数字放在一起比对的机制**。这份规则卡就是那个比对清单。
>
> **修订纪律（最重要的一条）**：规则只能在季度或年度复盘时修改，且必须在下方变更记录里写明原因。
> **绝对不允许**在想做某笔交易的当下修改规则来让这笔交易合规——那等于没有规则。

## 零、口径定义

所有百分比规则的分母是**合并净值**：全部美股账户的净清算价值之和，不含房产与国内理财。

截至 2026-08-01，已录入的账户只有 IB U17325285（净值 427,418 美元）。
其余账户数据补齐前，下表「当前值」栏按**单账户口径**填写并标注 `[单]`，补齐后必须按合并口径重算。
两个口径会给出方向相反的误判：单账户口径高估期权敞口比例，同时低估个股穿透集中度。

## 一、仓位规则

| 编号 | 规则 | 阈值 | 2026-08-01 当前值 | 状态 |
|------|------|------|-------------------|------|
| P1 | 单一标的穿透后占比 | ≤ 20% | MSFT 25.3% `[单]` | ✗ |
| P2 | 处于 15–20% 区间的标的数量 | ≤ 1 只 | MSFT 25.3%、TSM 18.0% `[单]` | ✗ |
| P3 | 前三大穿透后合计 | ≤ 45% | 55.2%（MSFT+TSM+NVDA）`[单]` | ✗ |
| P4 | 单一行业或主题穿透后占比 | ≤ 35% | 半导体与 AI 算力 35.5% `[单]` | ✗ |
| P5 | 卫星投机仓合计（见定义） | ≤ 5% | DRAM 1.2% `[单]` | ✓ |
| P6 | 同一底层指数的宽基 ETF | 只允许持有 1 只 | QQQM 与 IQQ 同为纳斯达克100 | ✗ |
| P7 | 防守型资产（医疗/必需消费/公用事业/短债） | ≥ 10% | 3.7%，且全部为 ETF 附带、无一只是主动配置 `[单]` | ✗ |

**卫星投机仓的定义**：无法用 PE、DCF 或任何方法算出价值底的标的。判据很简单——
如果被套后你答不出「跌到多少算便宜」，它就是投机仓，不是投资仓。
DRAM 属于此类（其 playbook 第三节已明确写出「价值底测算在这里失效」）。

**P1–P3 的执行方式**：超限不等于立刻卖出。优质公司因上涨而超限，优先用「不再加仓 + 新增资金投向别处 + 卖 Covered Call 收租」被动稀释；
只有在超限**且**估值处于历史高分位时才主动减仓。因基本面恶化而超限则另按标的档案的失效条件处理。

## 二、现金规则

| 编号 | 规则 | 阈值 | 2026-08-01 当前值 | 状态 |
|------|------|------|-------------------|------|
| C1 | 现金与短债占合并净值 | ≥ 10%（市场估值处历史高分位时 ≥ 15%） | 0.01%（37.06 美元）`[单]` | ✗ |
| C2 | 现金停放方式 | 短债 ETF（SGOV 等）或货币基金，不留活期 | 无 | ✗ |
| C3 | 单账户现金 | ≥ 该账户期权保证金占用的 50% | 37.06 / 约 53,000 = 0.07% `[单]` | ✗ |

**为什么现金是硬规则而不是残值**：「不追高」纪律的执行方式是「宁可持有现金等待」。
如果现金比例为零，这条纪律在物理上就无法执行——回调来临时你没有弹药，只能眼看着机会过去，
或者违反纪律去融资买入。**现金不是没投出去的钱，是这套策略的核心武器。**

C3 的存在是因为期权保证金占用会随行情膨胀。QCOM 手册第九节风险管理第 1 条已写明
「保留充足现金/短债（如 SGOV）作为波动率飙升时的缓冲弹药」，但账户现金是 37.06 美元。

## 三、期权规则（本卡的核心）

### 3.1 两类 Sell Put 必须分开定义、分开设额度

| | 接货型 Sell Put | 收租型 Sell Put |
|---|---|---|
| 意图 | 在认可的价位接货建仓 | 赚权利金，不打算持有正股 |
| 最坏结果 | 以我认可的价格买到好公司 | 在暴跌中用高价现金平仓，无任何资产留下 |
| 本质 | 买入纪律的执行工具 | 做空波动率 |
| 担保方式 | **必须 100% 现金担保** | 保证金担保，但需备平仓弹药 |
| 是否需要标的档案 | 是，且必须写明合理买入区间 | 否，但需写明止损线 |
| 是否需要 playbook | 是 | 是 |

这两类的名字都叫「Sell Put」，风险性质却完全相反。混在一起统计是 2026-08-01 复盘发现的首要问题：
文档写的是接货型，实际执行的是收租型，现金缺口 325,863 美元。

### 3.2 额度规则

| 编号 | 规则 | 阈值 | 2026-08-01 当前值 | 状态 |
|------|------|------|-------------------|------|
| O1 | 接货型 Put 名义总额 | ≤ 现金与短债余额（即现金覆盖率 100%） | 0 / 37.06 | — |
| O2 | 收租型 Put 名义总额 | ≤ 合并净值 10% | 325,900 = 76.2% `[单]`（合并口径约 29.6%） | ✗ |
| O3 | Put 名义总额合计 | ≤ 合并净值 35% | 同上 | ✗ |
| O4 | **指数类** Put 名义总额 | ≤ 合并净值 10% | 241,900 = 56.6% `[单]`（合并约 22%） | ✗ |
| O5 | 同一到期日的 Put 名义总额 | ≤ 合并净值 10% | 2026-09-18 单日 257,400 = 60.2% `[单]` | ✗ |
| O6 | 收租型 Put 的平仓弹药 | ≥ 收租型名义的 30%，以现金或短债持有 | 37.06 / 97,770 = 0.04% | ✗ |

**O4 单列指数 Put 的理由**：SPYM 和 QQQ 的 Put 与你的股票组合是接近完全正相关的。
市场下跌时，股票在亏、Put 在亏、保证金要求同时膨胀，三件事发生在同一天。
个股 Put 至少还有分散效应，指数 Put 一点都没有——它是在已有的多头敞口上再叠一层同方向杠杆。

**O5 的理由**：目前 325,900 名义里有 257,400（79%）集中到期于 2026-09-18，
而这天恰好是季度三重结算日（9 月第三个周五），本身就是波动放大的日子。

### 3.3 行权价规则（封堵「变相追高」）

**每一张 Sell Put 在开仓前必须同时通过以下三关，任何一关不过即放弃：**

| 关卡 | 个股 | 宽基指数 ETF |
|------|------|--------------|
| 第一关：绝对位置 | 行权价 ≤ 52周高点 × 0.85 | 行权价 ≤ 52周高点 × 0.85 |
| 第二关：估值锚 | 盈亏平衡点（行权价 − 权利金）≤ 标的档案中写下的「合理买入区间上限」 | 盈亏平衡点对应的指数前瞻 PE ≤ 近 10 年中位数 |
| 第三关：安全垫 | 行权价 ≤ 现价 × 0.85 | 行权价 ≤ 现价 × 0.90 |

对无法算价值底的卫星投机仓（如 DRAM），第二关替换为其 playbook 的专门规定
（DRAM 手册要求深虚值 -25% 以上）。

**2026-08-01 逐张检查结果**

| 标的 | 行权价 | 现价 | 52周高点 | 第一关（≤高点×0.85） | 第三关（安全垫） | 判定 |
|------|--------|------|----------|---------------------|-----------------|------|
| SPYM | 86 | 87.65 | 89.52 | 需 ≤ 76.09 | 需 ≤ 78.89 | ✗ 双关不过 |
| SPYM | 84 | 87.65 | 89.52 | 需 ≤ 76.09 | 需 ≤ 78.89 | ✗ 双关不过 |
| SPYM | 83 | 87.65 | 89.52 | 需 ≤ 76.09 | 需 ≤ 78.89 | ✗ 双关不过 |
| QQQ | 630 | 约 680 | 约 700（待核） | 需 ≤ 595 | 需 ≤ 612 | ✗ 双关不过 |
| QQQ | 620 | 约 680 | 约 700（待核） | 需 ≤ 595 | 需 ≤ 612 | ✗ 双关不过 |
| QCOM | 155 | 约 145–150 | 约 205（待核） | 需 ≤ 174 | 需 ≤ 123（开仓时约 161） | ✓ 第一二关过 |
| DRAM | 55 | 49.80 | 约 72 | 需 ≤ 61.2 | playbook 要求 ≤ 52.5 | △ 第一关过，playbook 不过 |

结论：问题不在个股 Put。QCOM 那张行权价选得很有纪律——盈亏平衡点 147.06 落在其 playbook 测算的
价值底 150–160 下方，完全符合「在认可价位接货」的定义。**问题全部集中在三组指数 Put 上**，
它们占了 74% 的名义敞口，而行权价距 52 周高点只有 4%–15%。

**这一节要防的就是这件事**：把 Sell Put 当成「不追高」的执行工具是对的，但只有当行权价真的落在
你认可的低估区间时才成立。行权价贴着现价卖，实质是一张延后执行的追高限价单，只不过附赠了权利金。

### 3.4 强制处理线（触发即执行，不得无动作）

| 编号 | 触发条件 | 强制动作 | 时限 |
|------|----------|----------|------|
| T1 | 权利金缩水至开仓价的 40–50%（即浮盈 50–60%） | 止盈平仓，释放保证金 | 下一个交易日 |
| T2 | 单笔浮亏达 100%（权利金翻倍） | 平仓认亏，或按 playbook 展期，二选一 | 48 小时内 |
| T3 | 正股跌破 playbook 写明的铁底价 | 按 playbook 的防御性展期条款执行 | 48 小时内 |
| T4 | 组合总保证金占用超过净值 25% | 减仓至阈值以下 | 5 个交易日内 |
| T5 | 距到期 21 天且仍为实值 | 决定接货或展期，并确认接货资金到位 | 立即 |

**「无动作」本身就是违规。** T1–T5 允许你选择怎么做，但不允许你什么都不做然后等着看。
这条是针对已经发生的事实写的：QCOM 那张 Put 早已同时触发 T2 和 T3，DRAM 那张接近 T2，
两者都在两份 playbook 里有明文规定，但都没有执行。
